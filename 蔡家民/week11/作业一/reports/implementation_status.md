# 本地验收记录

本记录说明工程可运行性，不提供大模型性能结论。

## 验证结果

- 47项unittest通过，包含120道回放路径的子测试及Notebook离线代码执行。
- 120题数据集、79个查询模板族，20/40/60切分及指纹检查通过。
- 112条参考SQL执行、结果快照及必要表注释核对通过；11项独立Python统计核验通过。
- 112题查询结果在回放中匹配，4题澄清与4题不支持状态匹配。
- 独立30项校验专项：24项错误检出，6项正确对照没有误报；16项显式修复回放成功。
- 3组独立反例通过，原数据库保持不变。
- 独立环节、标准上游替换和三轮重复实验协议已完成离线验证。
- HTTP模型适配器只做了Mock响应测试，没有真实网络模型调用。
- `scripts/verify.py`可重新运行完整检查；机器可读结果见verification.json。

测试覆盖：数据库解析、外键桥接、COUNT(*)授权行为、空表、只读与函数限制、参数绑定、递归计算中断、截断、SQL编译、金额粒度风险、日期边界缺失、选表范围、修复、重复终止、NULL/0/空结果、结果比较、客户端配置、用量记录隔离。

## 已知边界

SQL语义规则是有限风险检查，不能证明所有SQL正确。没有进程级内存隔离。澄清/拒绝目前只自动比较状态。题目已完成作者侧审阅与自动核对，不冒充独立第三方人工认证，也不声称排除全部语义近似性。

需要模型配置后才能执行：真实模型联调、实际对比/消融/稳定性实验与可选裁判评分。没有虚构这些实验的成绩。配置步骤见docs/handoff.md。

## 复现

```powershell
python scripts/verify.py
```

运行过程中仅写项目自己的artifacts与reports；测试使用临时数据库副本，不修改课程原始数据库。
