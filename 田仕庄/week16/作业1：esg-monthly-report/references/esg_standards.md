# ESG 标准与评级速查

> 用途：撰写月报「一、ESG 政策 / 评级 / 标准动态」（README §9 表1）时核对口径。
> 原则：只引用公开可查的官方原文与评级机构公开方法；评级数据缺失标 `N/A`，不推测。本文件是速查线索而非权威全文，引用前以官方最新发布为准。**复核周期：每年至少一次（上次：2026-11）。**

## 1. 国际披露准则与框架

| 名称 | 发布方 | 要点 | 月报关注点 |
|---|---|---|---|
| IFRS S1 / S2 | ISSB（IFRS 基金会） | 2023-06 发布，2024-01 生效：S1 可持续相关财务披露通用要求，S2 气候专项（吸收 TCFD 建议） | 各国/地区采纳进度、与 A 股指引的衔接 |
| GRI Standards | GRI | 2021 版通用准则 2023-01 生效，行业准则陆续发布；影响导向 | 央企/上市公司 ESG 报告是否采用、准则修订 |
| SASB Standards | 原 SASB，2022 年起由 ISSB 接管维护 | 分行业财务实质性指标 | 煤炭/电力行业指标引用 |
| TCFD | FSB 设立 | 2017 年发布建议；监测职责已由 ISSB 承接，内容并入 IFRS S2 | 治理/战略/风险管理/指标目标四支柱表述 |
| GHG Protocol | WRI / WBCSD | Scope 1/2/3 核算的通用方法学 | 温室气体核算口径与第三方核证 |
| CDP | CDP（非营利） | 气候/水/森林问卷；评级 A–D-，未回复为 F | 客户及对标企业的 CDP 评级与变动 |
| UNGC 十项原则 / SDGs | 联合国 | 企业责任与可持续发展目标框架 | 央企报告常见框架映射 |

**双重重要性**：财政部可持续披露基本准则与沪深北交易所指引均引入「影响重要性 + 财务重要性」双重视角；月报提及准则时使用「双重重要性」表述。

## 2. 主流评级机构

| 机构 | 产品 | 刻度/分档 | 使用注意 |
|---|---|---|---|
| MSCI | ESG Ratings | AAA / AA / A / BBB / BB / B / CCC 七档 | 行业调整后相对评分；只写公开评级与变动，不推演分数 |
| S&P Global | ESG Score（CSA） | 0–100 分 | 年度 CSA 结果；注明问卷年度 |
| CDP | 气候/水/森林评级 | A / A- / B / B- / C / C- / D / D-，未回复 F | 区分「评级」与「回复状态」 |
| Sustainalytics | ESG 风险评分 | 0–100，**分数越高风险越高**；0–10 可忽略、10–20 低、20–30 中、30–40 高、≥40 严重 | 与 MSCI 方向相反，引用时必须写清「风险评分」 |
| 华证 | 华证 ESG 评级 | AAA / AA / A / BBB / BB / B / CCC / CC / C 九档 | 国内常用；注明评价期 |
| 中证指数 / Wind | ESG 评价/评级 | 分档以机构官网最新披露为准 | 不同机构口径不可直接比较 |

**写作约束**：评级变动只做事实陈述与影响分析；不预测评级走向；未公开的分数/分档一律 `N/A`。
