## 1. 项目背景

### 1.1 业务痛点

| 痛点 | 现状 | 影响 |
| --- | --- | --- |
| 取数门槛高 | 业务方需提需求给数据分析师写 SQL | 需求排队，平均等待 1~3 天 |
| 口径不统一 | 同一指标在不同报表口径不一致 | 决策依据冲突，信任度下降 |
| 自助 BI 难用 | 拖拽式 BI 需理解表结构和建模 | 业务方学习成本高，使用率低 |
| 长尾需求多 | 大量一次性、临时性取数需求 | 分析师被低价值工作占用 |

### 1.2 项目定位

构建一套面向业务人员的**对话式数据分析平台（ChatBI）**，用户用自然语言提问，系统自动完成
**意图理解 → 指标映射 → SQL 编译 → 执行 → 可视化 → 结论解读** 全链路，返回可信、口径统一的答案。

**与"直接让大模型写 SQL"的本质区别**：本项目通过**语义层 + 受控查询 DSL** 收敛生成空间，
把开放域 Text2SQL 降维成受控的指标查询编译，从根本上保证准确率与口径一致性。

## 2. 项目目标

### 2.1 业务目标

| 编号 | 目标 | 衡量方式 |
| --- | --- | --- |
| G1 | 降低取数门槛，业务自助取数 | 自助取数占比 ≥ 60% |
| G2 | 统一指标口径 | 核心指标口径一致率 100% |
| G3 | 缩短取数时效 | 常见问题从"天级"降到"秒级" |
| G4 | 释放分析师产能 | 分析师临时取数需求下降 ≥ 50% |

### 2.2 技术目标

| 编号 | 目标 | 指标 |
| --- | --- | --- |
| T1 | 查询准确率 | 核心业务域执行准确率（EX）≥ 90% |
| T2 | 响应性能 | P95 端到端响应 ≤ 5s |
| T3 | 并发能力 | 支持 50 并发查询，错误率 < 1% |
| T4 | 安全合规 | 行/列级权限 100% 强制注入，全量审计 |

### 2.3 非目标（本期不做）

- ❌ 不做数据抽取/ETL 工具（对接现成数仓/数据源）
- ❌ 不做复杂预测建模、机器学习训练
- ❌ 不做实时流式数据（仅支持 T+0/T+1 批数据查询）
- ❌ 不做写操作（禁止 INSERT/UPDATE/DELETE/DDL）

## 3. 项目范围

│                       ChatBI 平台                          │

          ▲                                    ▲

## 7. 风险与应对

| 编号 | 风险 | 等级 | 应对措施 |
| --- | --- | --- | --- |
| R1 | 准确率不达预期，用户不信任 | 高 | 受控 DSL 路线；澄清反问兜底；先窄域验证再扩域 |
| R2 | 语义层维护成本高，无人维护 | 高 | 绑定业务 owner；可视化编辑降门槛；纳入考核 |
| R3 | 指标口径争议 | 中 | 审批工作流；口径文档化；变更审计 |
| R4 | 数据权限越权/泄露 | 高 | 编译期强制注入过滤；只读账号；全量审计 |
| R5 | 大模型幻觉（编造字段/数据） | 中 | 禁止 LLM 直连数据库；结果标注来源 SQL |
| R6 | 大模型成本/延迟高 | 中 | 大小模型分工；结果缓存；vLLM 私有化部署 |
| R7 | 复杂查询（同比/留存/归因）准确率低 | 中 | 复合指标内置；复杂问题转人工/模板兜底 |
| R8 | 上游数仓口径变更导致结果漂移 | 中 | 数据血缘 + 语义层版本管理 |

## 8. 依赖与约束

**依赖**
- 数仓/数据源提供稳定只读访问账号
- 现成 ETL/建模平台产出 DWD/DWS 层
- 业务方配合梳理指标口径
- 大模型服务（云 API 或私有化推理）

**约束**
- 数据库只读，禁止任何写操作
- 必须在编译期完成权限注入，不依赖 LLM
- 单次查询超时 ≤ 30s，返回行数 ≤ 10 万
- 数据不出域（涉密场景私有化部署）

## 10. 术语表

| 术语 | 含义 |
| --- | --- |
| ChatBI | 对话式商业智能（Chat + BI） |
| 语义层 | 业务语言与物理表字段的映射层（指标/维度/模型） |
| 指标 Metric | 可聚合的业务度量，含表达式与口径 |
| 维度 Dimension | 可切分数据的视角，含层级与枚举 |
| DSL | 受控查询语言（指标 + 维度 + 过滤 + 时间） |
| EX（Execution Accuracy） | 执行准确率，SQL 执行结果与标准答案一致 |
| Schema Linking | 从大量表字段中召回相关表和字段 |
| 原子/派生/复合指标 | 指标三层结构：基础聚合 / 加限定 / 指标间运算 |
