## 3. 功能详细设计

### F1 自然语言问答（NL2SQL）

**功能描述**：用户输入自然语言问题，系统自动完成数据库解析、表选择、SQL 生成、校验、改写、执行、结果汇总，返回自然语言答案 + 数据结果。

**用户故事**：作为业务运营，我希望用自然语言提问，就能得到准确的数据结果，而无需自己写 SQL。

**输入**：自然语言问题（中文为主，支持数字、时间、实体名）。

**输出**：
- 自然语言答案（结果汇总）
- 结构化结果表格
- 生成过程（SQL、所用表、校验/改写日志）

**验收标准**：
- 输入「每个艺术家有多少张专辑」能正确返回聚合结果。
- SQL 执行成功率达到目标值；失败时能自动改写并重试（最多 N 次）。
- 端到端响应 ≤ 5s（流式输出首 token ≤ 2s）。

---

### F2 结果可视化

**功能描述**：根据结果类型自动选择合适的图表展示。

**图表选型规则**（示例）：

| 结果特征 | 图表类型 |
| --- | --- |
| 单值（count/sum） | 指标卡 |
| 类别 + 数值（TopN） | 柱状图 / 横向条形图 |
| 占比（百分比） | 饼图 / 环形图 |
| 时间序列 | 折线图 / 面积图 |
| 二维明细 | 表格 |

**验收标准**：返回多行类别-数值结果时自动渲染柱状图；时间序列自动渲染折线图。

---

### F3 SQL 生成过程透明化

**功能描述**：用户可查看本次回答背后的 SQL、用到的表、以及校验/改写过程，建立信任与可追溯性。

**展示内容**：
- 选中的表列表
- 生成的 SQL（可一键复制）
- 校验状态与改写记录
- 数据来源字段说明

**验收标准**：任意一次回答都能展开查看完整生成链路。

---

### F4 多轮对话与追问

**功能描述**：系统维护会话上下文，支持追问与纠错。

**典型交互**：
- 用户：「各区域销售额」 → 系统返回汇总。
- 用户：「按月呢？」 → 继承上下文（区域 + 销售额），切换时间维度。
- 用户：「只看华东」 → 增加过滤条件。
- 用户：「不对，我要的是利润」 → 纠正指标。

**验收标准**：支持上下文继承（维度/指标/过滤条件）；支持用户纠正并重新查询。

---

### F5 数据源与元数据管理

**功能描述**：接入关系型数据库，自动解析并维护表结构、字段、外键关系、字段统计信息（distinct、min/max、样例、缺失率）。

**能力**：
- 数据源连接配置（地址、账号、只读校验）
- 元数据自动解析（表/字段/主外键/统计）
- 表与字段的业务别名维护（可选）
- 敏感字段标记

**验收标准**：新增数据源后自动完成解析并可用于问答。

---

### F6 权限与数据安全

**功能描述**：保障数据只读、最小权限、敏感信息不泄露。

**能力**：
- 只读账号连接，禁止 DDL/DML。
- 字段级权限：敏感字段（工资、手机号、密码）按角色脱敏或禁查。
- 审计日志：记录谁在何时问了什么、执行了什么 SQL。
- 结果导出受权限控制。

**验收标准**：
- 任何非 SELECT 语句一律拦截。
- 越权访问敏感字段返回「无权限」而非数据。
- 审计日志可回溯。

---

### F7 历史记录与收藏

**功能描述**：保存用户查询历史，支持收藏、复用、分享。

**验收标准**：可查看历史问答、一键复用 SQL、分享结果。

---

### F8 评测与反馈

**功能描述**：对回答结果收集用户反馈，沉淀评测集，用于持续优化准确率。

**能力**：
- 结果点赞/点踩 + 原因标签（结果错误/SQL 错误/口径不对）。
- 人工标注理想 SQL 与理想结果。
- 基于评测集回归测试。

**验收标准**：能导出评测集，并统计准确率变化。

---

### F9 指标口径（语义层）

**功能描述**：沉淀指标与维度字典，解决「同名不同义」问题。

**示例**：
- 指标「销售额」= `SUM(invoices.Total)`，口径统一。
- 维度「区域」= 客户所在 `Country` 字段。

**验收标准**：配置指标后，涉及该指标的提问统一使用定义口径。

## 4. 用户主流程

```
用户输入问题
   │
   ▼
[1] 意图识别 / 会话上下文合并
   │
   ▼
[2] 表选择（结合 schema + 外键 + 样例）
   │
   ▼
[3] SQL 生成
   │
   ▼
[4] SQL 校验 ──失败──▶ [5] SQL 改写 ──▶ 回到 [4]
   │ 通过
   ▼
[6] SQL 执行（只读）
   │
   ▼
[7] 结果汇总 + 图表选型
   │
   ▼
返回：自然语言答案 + 表格/图表 + SQL 过程
```

## 5. 非功能需求

| 类别 | 需求 |
| --- | --- |
| 性能 | 端到端 ≤ 5s；流式输出；并发 ≥ 50 QPS |
| 可用性 | 服务可用性 ≥ 99.9%；异常有友好提示 |
| 安全 | 只读、字段级权限、审计、敏感信息脱敏 |
| 可维护性 | 模块化（选表/生成/校验/改写/执行/汇总可独立替换） |
| 可扩展 | 支持接入多数据源、多模型、自定义工具（MCP） |
| 可观测 | 日志、埋点、评测指标可视 |
