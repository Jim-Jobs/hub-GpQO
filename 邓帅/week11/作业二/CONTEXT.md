# chinook-chatbi

用自然语言问 chinook 音乐销售数据的对话式 BI 项目：前端对话界面 + 业务 Server（对话编排与持久化）+ 无状态 MCP Server（七步 SQL 分析链路）。

## Language

**会话（session）**:
一段连续的多轮问答，有唯一标识与标题；首条消息发出时创建，切换会话随时可用。
_Avoid_: 对话、conversation

**轮（turn）**:
一次问答 = 一条用户消息 + 一条助手消息。轮状态：running（分析进行中）/ done（完成）/ failed（失败，含已尝试 SQL 与错误）。
_Avoid_: 回合、round

**问题改写**:
编排层把含指代的问句改写为自包含问题的动作，发生在送去分析之前；结果对用户可见（"理解为：…"）。
_Avoid_: 指代消解（单独使用）、改写（无限定词时与 SQL 改写歧义）

**SQL 改写**:
七步链路第 ⑤ 步，校验失败后重写 SQL 的重试动作，上限 3 次尝试。与问题改写是两个概念。
_Avoid_: SQL 修正、SQL 修复

**七步链路**:
解析 → 选表 → 生成 → 校验 → 改写 → 执行 → 汇总的 SQL Agent 分析流程，整体封装在 MCP 工具 analyze 内。
_Avoid_: pipeline（口语可，正式文档用"七步链路"）

**步骤轨迹（steps trace）**:
一轮中七步各步的名称、状态、摘要与 SQL 尝试记录；随轮落库，回看时完整重放。
_Avoid_: 过程日志、trace（单独使用）

**chart spec**:
汇总步产出的图表描述契约（类型 / 标题 / 轴 / 数据行）；type 为 null 表示该轮不配图（如单值答案）。
_Avoid_: 图表配置（与 ECharts option 混淆）

**占位标题 / 正式标题**:
会话标题两种形态——首轮进行中以问题前 12 字占位；首轮回答完成后由 LLM 生成 ≤12 字正式标题，失败保持占位。
_Avoid_: 临时标题
